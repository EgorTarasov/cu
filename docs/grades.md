# cuni grades

Показывает оценки: сводку по всем курсам или подробную ведомость по конкретному.

## Использование

```bash
cuni grades                 # сводка по всем курсам
cuni grades go              # ведомость курса Go
cuni grades 901             # по ID
cuni grades алгоритмы       # по названию
```

## Пример — сводка

```
$ cuni grades
Grades summary

  Java Spring (Разработка веб-приложений на Java с …  [#######-------------] 3.6/10
  SQL и базы данных (для разработчиков)               [####----------------] 2.5/10
  Алгоритмы и структуры данных. Часть 2               [####----------------] 2.0/10
  Разработка на языке программирования Go             [##------------------] 1.1/10

Use: cuni grades <course> for detailed view
```

## Пример — подробная ведомость

```
$ cuni grades алгоритмы
Grades: Алгоритмы и структуры данных. Часть 2

Activity breakdown:
  Теоретические домашние задания (20%)  avg=0.0  total=0.0
  Контесты (30%)                       avg=6.7  total=2.0
  Экзамен (50%)                        avg=0.0  total=0.0
  Устная защита                        avg=5.0  total=0.0 [BLOCKER]

  Total score: 2.0

Tasks:
  FAILED          0/10  #1530918   Подача заявления на перезачёт дисциплин
  DONE           10/10  #1531204   ДЗ 1. Неделя 3. «Контест 1»
  DONE           10/10  #1531205   ДЗ_1_Неделя 3_Устная защита
  DONE           10/10  #1533871   ДЗ 2. Неделя 6. «Контест 2»
  TODO            -/10  #1533872   ДЗ 2_Неделя 6_Устная защита
  TODO            -/10  #1536744   ДЗ 4. Неделя 12. «Контест 3»

  Устная защита (need avg >= 10)

  cuni task <id> for details
```

Число после `#` — ID задачи для `cuni task <id>`.

## Что показывается

**Сводка** — прогресс-бар и набранный балл из максимума для каждого курса.

**Ведомость** содержит:
- **Activity breakdown** — баллы по типам активностей (ДЗ, контесты, экзамен) с весами
- **Tasks** — статус и оценка по каждому заданию
- **Blockers** — активности, блокирующие итоговую оценку (нужен минимальный средний балл)
